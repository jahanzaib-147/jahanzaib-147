Hi, I'm **Muhammad Jahanzaib**. I'm a Computer Science graduate (GPA 3.6 / 4.0, Iqra University) specializing in **Cybersecurity Operations (SOC)**, **Enterprise Network Defense**, and **Systems Architecture**, combined with practical **Full-Stack Development** for commercial and freelance client platforms.

My primary expertise lies in defensive security operations, threat triage, Cisco network segmentation, and automation scripts. In parallel, I actively build and deploy hardened, modern web applications and SaaS MVPs using **React, Next.js, TypeScript, and Python** for clients who require secure, production-ready code.

- 🛡️ **Security Operations (SOC) & Threat Analysis**: Former SOC Analyst Intern at **Jubilee Life Insurance** — Triaged high-volume IBM QRadar SIEM/SOAR alerts, filtered true positives, investigated threat intelligence indicators, and executed endpoint containment using Trellix EPP & Carbon Black EDR.
- 🌐 **Enterprise Network Defense & Architecture**: Designed robust perimeter security and multi-campus network topologies utilizing Cisco ASA stateful firewalls, dynamic OSPF routing, and Zero-Trust VLAN/DMZ segmentation.
- 💻 **Software & Security Automation**: Engineered high-performance distributed simulation engines, automated security workflows in **Python & PowerShell**, modeled system diagrams in **Mermaid**, and built script security analysis tools.
- 🚀 **Full-Stack & SaaS Engineering (Client & Freelance)**: Building responsive web applications and SaaS platforms with **React, Next.js, Node.js, TypeScript, Tailwind CSS, and Python (FastAPI/Django)**. Leveraging defensive security principles to deliver hardened web apps with secure auth, Stripe payments, and clean database modeling.
- 📜 **Core Certifications**: **ISO/IEC 27001 Information Security Associate™** (SkillFront) & **Certified Threat Intelligence & Governance Analyst (CTIGA)** (Hack and Fix).
